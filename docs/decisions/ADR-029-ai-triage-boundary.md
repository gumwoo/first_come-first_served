# ADR-029 · 장애 초기 분석에 AI를 쓰는 범위: 수치는 스크립트, AI는 요약만 보고 후보와 근거를 낸다

- 상태: Accepted
- 날짜: 2026-10-21
- 관련: [[IMP-043]](예매 묶음 원인 분석, 수치 계산과 가설 검증을 사람이 한 사례), `infra/triage-lab/`(장애 주입 실험실), `scripts/triage/`

## 1. 맥락
부하 테스트 run의 원인을 찾을 때 CPU·Tomcat 스레드·Hikari·Redis·PostgreSQL 지표를 함께 봐야 한다. 지표 하나로는 원인이 갈리지 않는다.
[[IMP-043]]에서는 지표를 맞춰 보고 가설을 세우고 반증하는 일을 사람이 했다. 이 중 첫 단계, 즉 지표를 묶어 원인 후보와 근거를 내는 일을 도구로 돕는다.

위험은 두 가지다.
- LLM은 그럴듯한 설명을 만든다. 원자료에 없는 수치를 쓰거나 근거 없이 원인을 고를 수 있다.
- 측정 환경 자체가 무효인 run(호스트 저장소 지연 등)을 장애로 설명할 수 있다.

## 2. 결정
1. **서비스 런타임과 분리한다.** 예매 서비스에는 붙이지 않는다. run 디렉터리를 입력으로 받는 운영 도구(`scripts/triage`)다.
2. **수치는 스크립트가 계산한다.** `normalize.mjs`가 누적 지표 차분으로 구간 값을 만들고, 측정 무효 여부도 규칙으로 판정한다. AI는 이 요약 JSON만 받는다.
   원자료·문서·라벨·파일 이름은 보내지 않는다.
3. **AI를 부르는 run을 줄인다.** 측정 무효이거나 규칙 분류기가 이상 없음으로 본 run은 부르지 않는다.
4. **출력 형식을 고정한다.** 도구 하나(`report_diagnosis`, strict)로 JSON 스키마에 맞는 답만 받는다. tool_choice는 auto로 두고 프롬프트로 호출을
   지시하며, 도구를 부르지 않은 응답은 실패로 처리한다. Haiku 5.5는 강제 도구 호출을 받지만 생각 없이 바로 호출하고, Sonnet 5.5는 400으로 거부한다.
   항목은 판정(원인·정상·판단 불가), 원인 후보 순위, 근거, 반대 지표, 확인하지 못한 데이터, 다음에 확인할 것이다.
5. **근거 수치를 대조한다.** 근거마다 요약 JSON의 필드 경로와 값을 달게 하고 `verify.mjs`가 다시 찾는다. 하나라도 없거나 다르거나 숫자가 아니면,
   또는 원인 판정에 근거·후보가 없으면 그 답은 판단 불가로 바꾼다.
6. **조치하지 않는다.** 설정 변경이나 클러스터 조작을 하지 않고, 지시하지도 않는다. 후보와 근거를 사람에게 보여 주고 사람이 판단한다.
7. **Messages API로 시작한다.** 입력이 정해진 단발 호출이라 재현·평가가 쉽고 비용이 작다. 에이전트가 원자료를 더 찾아보는 방식(Agent SDK)은 평가에서
   "확인하지 못한 데이터" 때문에 틀린 사례가 반복될 때 다시 검토한다. 그때도 읽기 전용 복사본과 허용한 조회 함수만 준다.
8. **비교 기준을 둔다.** 같은 요약으로 판정하는 규칙 분류기(`rules.mjs`)를 함께 두고, AI가 이보다 나은지 같은 사례로 비교한다.

## 3. 결과
- 키는 환경변수 `ANTHROPIC_API_KEY`로만 받는다. 모델은 `TRIAGE_MODEL`(기본 `claude-haiku-5-5`, effort medium, 샘플링 값은 기본값), 호출마다 모델·프롬프트 버전·토큰을 결과 파일에 남긴다.
- CI는 실제 API를 부르지 않는다. 요청 형식·대조·호출 조건은 가짜 client로 시험한다.
- SDK(`@anthropic-ai/sdk`)는 `scripts/triage/package.json`에만 두고, 실제 호출할 때만 불러온다.
- 기본 모델은 Haiku 5.5로 둔다(2026-10-22). 요약 수치를 읽고 원인 3범주 중 고르는 작업이고, 수치를 잘못 옮기면 대조기가 걸러 낸다.
  공개 토큰 단가(10만 토큰 이하 프롬프트, 100만 토큰당 입력 $0.10·출력 $0.50)가 Sonnet 5.5(입력 $2·출력 $10)의 1/20이다.
  이 도구의 프롬프트는 약 5천 자로 이 구간에 든다. 첫 실제 호출(Redis 주입 run)은 입력 3,671·출력 3,494토큰이었다.
- 효과는 장애 주입 run으로 평가한 뒤 IMP로 남긴다.
